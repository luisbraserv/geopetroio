🔍 Visão Geral do Sistema

O sistema Geopetro IO coleta dados em tempo real dos sensores instalados na sonda, processa os valores e os transmite via protocolo MQTT para o servidor de monitoramento. O operador acompanha tudo pelo aplicativo desktop instalado no computador conectado ao CLP.

O app conecta ao CLP via Snap7 (S7), lendo o Data Block 1 (DB1) a cada segundo. Os sinais analógicos 4-20 mA são convertidos para as unidades de engenharia corretas. Todas as leituras são também persistidas no banco H2 local para uso nos gráficos e na carta de operação.

🔌 Sensores do CLP

Vazão

B001 — Vazão

DB1.DBD0 — DWord (4 bytes)

Contador cumulativo de strokes da bomba de lama. A vazão em BBL/min é calculada pelo delta de strokes e pela constante da bomba.

📡 VAZAO_01
Peso

B002 — Peso da Coluna

DB1.DBW4 — Word (2 bytes)

Pressão hidráulica do sistema de içamento. Convertida para força (lbf) via área efetiva do pistão: lbf = (P - P₀) × área × fator.

📡 PESO_COLUNA_01
Torque

B003 — T. Ch. Hid. Tubos

DB1.DBW6 — Word (2 bytes)

Pressão efetiva no cilindro da chave de tubos. Torque em lbf·ft calculado via: T = P × A hidráulica × braço(ft). A área usa o pistão no avanço e a área anular pistão−haste no recuo.

📡 TORQUE_01
Torque

B004 — T. Ch. Flutuante

DB1.DBW8 — Word (2 bytes)

Pressão hidráulica da chave flutuante. Mesma lógica de B003 com parâmetros independentes.

📡 TORQUE_02
Pressão

B005 — P. Bomba de Lama / ESCP

DB1.DBW10 — Word (2 bytes)

Pressão da bomba de lama. Exibido nos cards "P. Bomba de Lama" e "ESCP". Sinal 4-20 mA convertido para PSI.

Conversão 4-20 mA: O CLP retorna 0–1000. Fórmula: corrente = (valor / 1000) × 20 mA → grandeza = ((corrente − 4) / 16) × rangeMax. Range configurável por sensor. B002 aplica cálculo adicional de força hidráulica após a conversão PSI.

⇄ Fluxo de Dados Detalhado

Leitura do CLP — a cada 1 segundo

Desktop conecta via Snap7, lê DB1. B001: DWord 4 bytes. B002–B005: Word 2 bytes cada.

Conversão e cálculo

PSI via 4-20 mA. Peso (lbf) via área hidráulica. Torque via pressão × área × braço. Vazão via delta strokes × constante bomba.

Exibição no monitoramento

Cards atualizados em tempo real. Visibilidade configurável individualmente.

Persistência local (SondaReading)

Cada leitura é salva no banco H2 local com timestamp, peso, torques, pressão e vazão. Usada pelos gráficos e carta de operação.

Envio ao Backend Telemetria — POST /leituras

HTTP para o Backend Telemetria. ID da sonda enviado junto para identificar o tópico MQTT.

Buffer local + publicação MQTT

Dados salvos em telemetria-buffer.json e publicados por tópico. Se o broker falhar, dados ficam no buffer e são reenviados no próximo ciclo.

Consumo no Backend Sonda

Inscrito em telemetria/sondas/+/dispositivos/+. Recebe, valida e encaminha para banco/InfluxDB.

Payload publicado — exemplo B002

  "nome":              "Peso Coluna",

ℹ

valorBruto: Para B002 o payload inclui a pressão bruta em PSI além do peso calculado em lbf. Útil para auditoria e diagnóstico do sensor.

💾 Buffer de Contingência

O arquivo ./data/telemetria-buffer.json é uma fila local que protege contra perda de dados quando o broker MQTT ou a internet estiver indisponível.

Leitura do CLP
→
Adiciona ao buffer JSON
→
Tenta enviar via MQTT
Sucesso ✓
→ Buffer limpo. Arquivo mantido para o próximo ciclo.
Falha ✗
→ Dados permanecem. Novos dados somados. Nova tentativa no próximo ciclo.
✅

Escrita atômica: Buffer escrito via .tmp e movido atomicamente — sem corrupção em caso de encerramento abrupto.

📈 Menu Gráficos

O menu Gráficos na barra superior permite visualizar os dados históricos armazenados no banco local, sem precisar gerar PDF. Ideal para análise em campo durante ou após a operação.

Como usar

Selecionar período

Informe data/hora de início e fim. Os dados do dia atual são carregados automaticamente ao abrir a tela.

Selecionar variáveis

Marque as variáveis desejadas: Peso Coluna, Torque Tubos, Torque Flutuante, Pressão Bomba e/ou Vazão.

Clicar em Atualizar

Os gráficos são gerados e exibidos na tela. Cada variável tem seu próprio gráfico empilhado verticalmente.

Zoom

Use os botões ＋ Zoom In / － Zoom Out ou o scroll do mouse sobre qualquer gráfico. O botão ↺ Resetar volta ao tamanho original.

⚙ Como Configurar o Aplicativo

Clique no botão ⚙ no canto superior direito para abrir as configurações gerais.

1. Configurações Gerais

IP do PLC

IP do CLP Siemens LOGO! na rede local. Ex.: 10.0.0.200. Clique em Conectar após alterar.

ID da Sonda / Unidade

Identificador único desta sonda. Usado no tópico MQTT. Ex.: SONDA-01. Cada sonda em campo deve ter um ID diferente.

URL do Backend de Telemetria

Endereço do servidor para envio dos dados. Ex.: http://192.168.0.10:8081. Deixe em branco para desativar envio remoto.

Cards visíveis

Marque/desmarque os sensores que devem aparecer no monitoramento. Sensores desmarcados não são enviados via MQTT.
