Uso técnico

Tokens prontos para servir de contrato visual entre design, web, desktop e mobile.

12

CSS — tokens essenciais

Copie a base para iniciar uma aplicação.

:root {
  --brand-navy-900: #051833;
  --brand-orange-600: #d4852f;
  --surface-canvas: #f7f9fc;
  --surface-raised: #ffffff;
  --border-default: #c9d4e8;
  --text-primary: #051833;
  --text-secondary: #5a667a;
  --radius-md: 5px;
  --space-4: 16px;
}

Regras de adoção

  • Use os tokens semânticos em vez de valores soltos dentro dos componentes.
  • Mantenha uma única ação azul de alta ênfase por grupo; use laranja somente como acento.
  • Garanta alvo mínimo de 44 px para controles usados por toque.
  • Combine status com texto ou ícone; cor isolada não comunica significado.
  • Teste fluxos em 320 px, 768 px e 1440 px antes de publicar.
  • Preserve foco visível, navegação por teclado e mensagens associadas aos campos.
